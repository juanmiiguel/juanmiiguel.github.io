# CartaQR Pro — MVP
Prototipo estático independiente de PresupuestaIA. Editor de categorías y platos, precios, descripciones, alérgenos, vista previa, guardado local y enlace compartible con QR.
URL prevista: https://juanmiiguel.github.io/cartaqr-pro/
Sin servidor, cuentas, pagos ni base de datos. Los enlaces compartidos codifican el contenido de la carta en la URL y no sirven como alojamiento permanente por establecimiento; las modificaciones requieren generar otro enlace/QR.
Los precios y los alérgenos del ejemplo son ficticios. El restaurante debe verificarlos.
No introducir información privada en la carta ni en el enlace.
